# 示例 Vault

这是一个可以导入 Obsidian 的示例知识库，用于展示 bright-book-breakdown 的输出效果。

## 使用方法

1. 下载 `vault-example.zip`
2. 在 Obsidian 中选择「打开保险库」→「打开本地保险库」
3. 选择解压后的 `vault-example` 文件夹
4. 开始探索

## 文件说明

```
vault-example/
└── books/
    ├── sources/
    │   └── 失去的制造业：日本制造业的败北.md   ← 读书笔记
    └── concepts/
        ├── 精益生产.md                         ← 概念页
        └── 现场主义.md                         ← 概念页
```

## 演示内容

这个 vault 展示了：

1. **读书笔记** → `失去的制造业：日本制造业的败北.md`
   - 叙事层：按篇章章节展开
   - 分析层：核心问题→论证链→边界条件

2. **概念页** → `精益生产.md`、`现场主义.md`
   - 一句话定义
   - 核心内容 + 操作指引
   - 关联概念（双向 wikilink）

3. **Wikilink 网络** → 读书笔记中的 [[wikilink]] 点击即可跳转

## 试试看

打开读书笔记，找到 `[[精益生产]]` 的链接，点击跳转到概念页，再从概念页的「关联概念」继续点击，体验网状知识网络。
