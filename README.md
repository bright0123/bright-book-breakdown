# Bright-Book-Breakdown

叙事体拆书工作流：从精读一本书到输出读书笔记 + 概念网络。

## 核心功能

- **三轮认知压缩**：骨架扫描 → 血肉解剖 → 灵魂提取
- **双层结构笔记**：叙事层（精读）+ 分析层（批判）
- **首次出现即链接**：用 `[[wikilink]]` 把概念织成网络

## 适用场景

- 拆解非虚构类书籍（教材、专著、方法论）
- 建立个人知识库（Obsidian）
- 生成可导航的概念网络

## 文件结构

```
bright-book-breakdown/
├── SKILL.md          # 技能定义文件
└── README.md         # 你现在看到的说明
```

## 使用方法

### 方式一：通过 Claude Code 调用

在 Claude Code 中输入：

```
/bright-book-breakdown 《书名》
```

### 方式二：集成到自己的 skills

1. 下载 `SKILL.md`
2. 放入你的 Claude Code skills 目录
3. 重启 Claude Code 即可使用

## 三轮认知压缩简介

| 轮次 | 目标 | 回答的问题 |
|------|------|-----------|
| 骨架扫描 | 建立全局结构 | "这本书在说什么" |
| 血肉解剖 | 理解论证链条 | "凭什么这么说" |
| 灵魂提取 | 超越作者 | "还能怎么用" |

## 与其他拆书方法的区别

- **vs 抄书笔记**：不是抄段落，是提取结构
- **vs 思维导图**：有叙事逻辑，有批判分析
- **vs 卡片盒**：强调首次出现即链接，形成可导航网络
