# 精益生产

> 由丰田汽车公司提出的生产管理方法，通过消除浪费、持续改善来实现高效、低成本的生产。

## 核心内容

精益生产（Lean Production）起源于丰田，其核心理念是**消除一切形式的浪费**。

### 七大浪费

| 浪费类型 | 说明 |
|----------|------|
| **过量生产** | 生产多于市场需求 |
| **等待** | 人员或设备无事可做 |
| **运输** | 不必要的物料搬运 |
| **加工** | 超出必要程度的加工 |
| **库存** | 原材料、在制品、成品积压 |
| **动作** | 人员不必要的移动 |
| **缺陷** | 需要返工或报废的不良品 |

### 两大支柱

- **准时化（JIT）**：在需要的时候、按需要的量、生产需要的产品
- **自働化**：发现问题立即停止生产线，让问题暴露

## 操作指引

### 如何识别浪费

1. 观察生产现场，追踪物料和人员的流动路径
2. 找出等待、搬运、库存积压的环节
3. 用"价值流图"（Value Stream Mapping）分析

### 实施步骤

1. **选定改善对象** — 从最影响成本的环节入手
2. **绘制现状图** — 记录当前流程的所有步骤
3. **分析浪费点** — 区分增值与非增值步骤
4. **设计改善方案** — 消除浪费，简化流程
5. **实施并验证** — 小规模试点，确认效果后推广

### 关键原则

- **小步快跑**：每次改善一小步，持续迭代
- **现场主义**：管理者要到生产现场发现问题
- **标准化**：改善后先标准化，再持续优化
